---
name: rh-revision
description: Изменение изделия без перерисовки — правка параметра в Grasshopper, пересчёт, re-bake и перевыпуск файлов. Для любого «поменяй/исправь/длиннее».
---
1. Найди слайдер в группе PARAMS. Нет параметра — добавь (чтобы следующий раз было одной цифрой).
2. Пересчитай, re-bake: старые объекты удаляются по слоям `PART::/TUBE::/SHEET::`, новые — с атрибутами.
3. Подними ревизию (User Text документа «Ревизия»), старые PDF/DXF/STEP → `_old/`.
4. Перевыпусти только затронутое; запись в `02_model/CHANGELOG.md` и params.md.
