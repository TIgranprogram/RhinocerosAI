# Регламент: от ТЗ до пакета на производство (Rhino + Grasshopper)

## 0. ТЗ → `02_model/params.md`
Габариты и управляющие параметры, состав (деталь: лист / труба / покупное / прочее), что будет меняться. **Согласовать до моделирования.**

## 1. Параметрическая модель (Grasshopper)
- Группа `PARAMS` (слайдеры с именами = params.md) → группа `SKELETON` (оси, точки, плоскости) → группы по узлам (`FRAME`, `SEAT`…) → группа `OUTPUT` (bake).
- Трубы: осевая линия + сечение из `10_LIBRARY/materials_profiles` → `Sweep1`/`Pipe`, торцы — Boolean/подрезка; каждая труба отдельным Brep.
- Лист: плоский контур + толщина (Extrude) или гнутая деталь с радиусом из стандартов; обязательна развёртка.
- Bake в `.3dm` скриптом `scripts/python/bake_with_attrs.py` (слой + User Text).

## 2. Проверка (`rh-checker`)
Closed Brep · нет пересечений деталей · развёртки строятся · атрибуты заполнены · длины труб ≤ станка.

## 3. Чертежи
Layout в шаблоне `.3dm`: детали (виды `Make2D`/детали Layout), размеры, штамп из User Text (`%<UserText(...)>%`). Экспорт PDF → `03_drawings_pdf`.

## 4. Экспорт на станки
- Лист → `_UnrollSrf` → плоский контур на XY → DXF 1:1 (только `CUT`, опционально `BEND`) → `04_dxf_laser`.
- Труба → каждый Brep отдельным STEP (AP214) → `05_tube_3d` → TubesT.
- BOM из атрибутов → XLSX → `06_bom`.

## 5. Документация
Рендеры видов (`_-ViewCaptureToFile`) → `07_render`; ТО и паспорт по шаблонам `_AI/templates_text` → `08`, `09`.

## 6. Ревизия
Меняем параметр в GH → пересчёт → re-bake (старые объекты по слою удаляются скриптом) → повтор 2–5 для затронутых деталей.

## Как Claude управляет Rhino
- **A. Скрипты Python 3 внутри Rhino 8** (ScriptEditor / `_-RunPythonScript`) — основной путь.
- **B. Grasshopper**: Claude готовит логику и код C#/Python-компонентов, вы собираете/открываете `.gh`.
